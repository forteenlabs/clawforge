# Current Direction

Build 0.0.5 — Integrity has been completed.

ClawForge now has accepted architecture for:

- sufficient Orientation before responsible participation
- impact classification for proposed changes
- Integrity evaluation against the authoritative pre-change state
- Lightweight Review for non-meaningful corrections
- Protected Changes and Challenge Review
- scoped implementation
- verification before acceptance
- deliberate finalization
- durable Integrity Memory

The immediate priority is post-build Orientation and deliberate selection of the next architectural question.

Future builds may address:

- machine-readable Integrity Records
- executable commands and interfaces
- an initial reference implementation
- external system and agent conformance
- bounded operation by a verified ClawForge agent

These are possible directions, not active or approved build scope.

The next build must be separately oriented, defined, and evaluated before work begins.
